## Modular Mobile Automation Framework

This repository contains a modular, industry-grade mobile automation framework built using **Appium**, **Java**, **Gradle**, and **TestNG**.

### Key Features
- Cross-platform automation for **Android and iOS**
- Single test logic with platform-specific page implementations
- Clean Page Object Model with shared business logic
- Config-driven execution (no hardcoded values)
- Scalable, maintainable, and interview-ready design

### Tech Stack
- Java 17
- Appium 2.x
- Gradle
- TestNG
- Android Emulator & iOS Simulator

This framework is designed for learning, real-world usage, and easy extension to any production mobile application.
